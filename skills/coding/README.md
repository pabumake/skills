# Coding

Reusable software-engineering disciplines.

- [code-review](./code-review/SKILL.md): Review a fixed change for correctness, regressions, maintainability, test quality, and specification gaps.
- [codebase-design](./codebase-design/SKILL.md): Design deep modules with small interfaces at clean seams.
- [diagnosing-bugs](./diagnosing-bugs/SKILL.md): Diagnose hard bugs through a tight feedback loop and falsifiable hypotheses.
- [domain-modeling](./domain-modeling/SKILL.md): Sharpen product language, scenarios, and durable technical decisions.
- [prototype](./prototype/SKILL.md): Build throwaway logic or UI experiments that answer one design question.
- [tdd](./tdd/SKILL.md): Implement behavior through small red-green test cycles.
- [technical-research](./technical-research/SKILL.md): Research engineering decisions from primary sources and save cited findings.
